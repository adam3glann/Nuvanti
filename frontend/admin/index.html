Pre-launch cleanup

Download a private backup before clearing test activity. The backup is a JSON export; keep it somewhere secure because it contains customer and order details.

Reset stays locked until a backup has downloaded. It deletes customers, orders, saved addresses, messages, newsletter subscribers, inventory adjustment history, visitor sessions and view totals. It restores stock reserved by non-cancelled test orders. Admin accounts, products and stock, photos, categories, collections, homepage slides and text, store settings, and discount codes are kept.
