Pre-launch cleanup

Download a private backup before clearing test activity. The backup is a JSON export; keep it somewhere secure because it contains customer and order details.

Reset stays locked until a backup has downloaded. It deletes customers, orders, saved addresses, messages, newsletter subscribers, inventory adjustment history, visitor sessions and view totals. It restores stock reserved by non-cancelled test orders. Admin accounts, products and stock, photos, categories, collections, homepage slides and text, store settings, and discount codes are kept.

Emergency store lockdown

Downloads the customer and order data snapshot, pauses new checkout, invalidates all staff and admin sessions, removes sign-in challenges, and blocks admin pages and new staff sign-ins. This does not rotate Railway, database, email, payment, or image-host credentials. The snapshot contains customer and order personal data; store it privately. Recovery requires Railway database access.

Restore from a backup file

Choose a previously downloaded Nuvanti JSON backup. This replaces the exported store data with that snapshot; current admin accounts and their passwords and MFA stay unchanged. Customer passwords, sessions, MFA secrets, Paymob transaction references, and private tokens are not in the file. Restored customers will need password resets; restore will not recreate payment-provider references or old newsletter unsubscribe links.
